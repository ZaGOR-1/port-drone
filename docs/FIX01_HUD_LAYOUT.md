# FIX-01 — розташування HUD

Редактор групи використовує наявну ширину `PcPort.sheet_w`, центрується за фактичним розміром і перераховується при зміні viewport або мінімального розміру вмісту. Довга підказка переноситься. ScrollContainer відкриває нижні дії у короткому вікні та підтримує прокрутку до фокуса. Анімація прозорості починається після розрахунку початкової позиції.

Обидва армійські popover вирівнюються по якорю, вибирають сторону з доступним місцем і обмежуються viewport. Високий список прокручується. Сигнали anchor, viewport і вмісту оновлюють розташування відкритого меню. Нижній редактор зберігає наявне врахування віртуальної клавіатури.

Розміри, запитані у fixture:

| Вікно | Масштаб UI | Мова |
|---|---:|---|
| 1280×720 | 130% | uk |
| 1366×768 | 100% | ru |
| 1600×900 | 70% | en |
| 1920×1080 | 130% | en |
| 960×540 після resize | 130% | uk |

Headless перевіряє геометрію. Ubuntu X11 перевіряє GUI й зберігає кадри. Віконний менеджер може зменшити фактичну площу доступного вікна. Скрипт перевіряє межі фактичного viewport. На Windows потрібні окремі DPI й візуальні перевірки.
