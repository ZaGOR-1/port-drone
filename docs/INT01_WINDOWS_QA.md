# INT-01 · Windows x64 QA · DroneFlames 0.36.1

Розпакуй ZIP повністю в окрему папку. Залиш три DLL поруч із EXE. У PowerShell, відкритій у папці пакета, звір контрольні суми й запусти гру. Для повторного запуску збережи значення `$qa`. Для чистого профілю або A/B вибери іншу папку.

```powershell
Get-Content .\SHA256SUMS.txt | ForEach-Object {
    $hash, $file = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash -ne $hash) {
        throw "SHA256 mismatch: $file"
    }
}
$qa = Join-Path $PWD.Path 'INT01-test-user'
$env:APPDATA = Join-Path $qa 'Roaming'
$env:LOCALAPPDATA = Join-Path $qa 'Local'
$env:DF_NO_UPDATE = '1'
$env:DF_NO_OPENING = '1'
Remove-Item Env:DF_LANG, Env:DF_STEAM_MOCK -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force $env:APPDATA, $env:LOCALAPPDATA | Out-Null
& .\DroneFlames.exe --log-file (Join-Path $qa 'INT01-engine.log')
```

## Windows A/B

Для перевірки впливу інтеграції на PERF-02 використай наявний `DroneFlames-PERF02-Windows-x64-c2cbb908.zip`. SHA256 `771d9e19e3985147278e55e6eb291ed02f760779003a05ebc1dc54ed1cf1d0f9`. Обидва пакети використовують Windows template Godot `4.7.2.stable.official.ed1daf0bf`. Для порівняння з початковим HUD і вводом є перевірений official комплект `c91e0e6` у `droneflames-toolchain/windows-build-c91e0e6.3lBIJY/package/`.

На одному ПК використай копії одного синтетичного checkpoint, однакову локаль, DPI, роздільність, масштаб UI, рендерер, обмеження FPS і позицію камери. Повтори A → B → B → A. Для кожної кількості цілей запиши тривалість додавання й підтвердження та p50/p95 frame time, якщо є засіб вимірювання. Preview CPU вимірюй лише з доступним профайлером. Для суб’єктивних вимірювань додай відео або короткий опис затримки.

## Передача результатів

Запиши SHA256 ZIP і EXE, ОС, CPU/GPU, DPI, розмір вікна, локаль і результат кожного рядка у форматі `PASS / FAIL / NOT RUN`. Скопіюй `INT01-engine.log` до наступного запуску. Після вильоту додай час, кроки, знімок екрана та запис Windows Event Viewer з Application Error, якщо він є. Перевір журнали й знімки перед передачею. Профіль цілком, saves, дані акаунтів і rejoin seats залиш у себе.
