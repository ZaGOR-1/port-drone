# Windows QA · контекстні цифрові клавіші

Погоджено числові прив’язки за порядком видимих кнопок активної панелі. Клавіші `F1–F7` відкривають відповідну панель, навіть якщо її вкладку вже вибрано. Повторний клік мишею по активній вкладці згортає панель. Клавіші верхнього ряду використовують фізичну позицію.

| Вкладка | Видимий порядок цифрових команд |
| --- | --- |
| F1 · Карта | `zoom_out`, `zoom_in`, `center`, `borders`, `map_modes`, `own_icons`, `ores` |
| F2 · Міста до столиці | `capital`, `town`, `farm`, `civ`, `power`, `solar_farm`, `mine`, `store`, `sawmill` |
| F2 · Міста після столиці | `town`, `farm`, `civ`, `power`, `solar_farm`, `npp`, `mine`, `store`, `sawmill` |
| F3 · Удари | `launch`, `route`, `recon`, `factory`, `droneport`, `missile`, `tel`, `mfactory`, `airfield` |
| F4 · ППО | `ad_mfg`, `ad_spaag`, `ad_sam`, `ad_patriot`, `ad_zaslon` (коли видимий), `ad_int`, `ad_radar`, `ad_ew`, `ad_rules` |
| F5 · Армія | `barracks`, `armies`, `command`, `doctrine`, `hold`, `defend`, `trench`, `teeth`, `dugout` |
| F6 · Політика | `diplomacy`, `trade`, `economy`, `ultimatum`, `scores` |
| F7 · Флот | `port`, `navbase`, `fleet`, `ship_cr`, `coastal_asm` |

Де команд менше дев’яти, зайві цифри ігноруються, доки панель відкрита. Приховані кнопки пропускаються. Видима disabled-кнопка зберігає номер, її натискання не викликає команду чи групу. `F8/F9/T` без ігрових прив’язок.

Текстовий фокус і модальні екрани блокують ігрові хоткеї. Під час розміщення або підтвердження дію цифр заблоковано. Стартовий режим столиці дозволяє контекстні команди до вибору точки. У дозволеному контексті `Ctrl+1–9` зберігає групу, звичайна цифра активує кнопку відкритої панелі або викликає групу після згортання панелі. Звичайна картка армії дозволяє виклик іншої групи. `Ctrl+1–9` без виділення очищає слот. Вибрана кнопка використовує її production `pressed` handler.

## Ручний QA

- До заснування столиці натиснути F2. Звірити підписи 1/2/3 зі столицею, містом і фермою. Порівняти поведінку з кліком по тих самих кнопках. Після вибору точки перевірити блокування цифр на підтвердженні.
- Заснувати столицю. F2 → 1/2/3 тепер місто, ферма, цивільний завод. Виходити з активного розміщення через Esc перед наступною командою. Перевірити цифри 4–9, повтор F2, утримання клавіші, EN/UA й відображення номерів на 70%, 100% і 130%.
- Зберегти дві різні армії в Ctrl+1/Ctrl+2. Згорнути панель кліком по активній вкладці. Викликати їх цифрами, двічі натиснути один номер для центрування. Відкрити F2 і перевірити, що цифри керують містами, а Ctrl+цифра працює з групою.
- Перевірити текстове поле, паузу з відкритим меню, панель швидкості й модальне вікно. Утримання хоткея не повторює команду.
- Натиснути 3 і B поза активною панеллю та клацнути карту. Тестовий удар не запускається. Відкрити штатний TEL із F3 і провести звичайний пуск у тестовому матчі.
- Перевірити Save/Continue, межі масштабу 70/130%, scrollbar, tooltip й кільце столиці. Окремі результати для фізичних розкладок, fullscreen/DPI та повного GUI наведено в [Windows QA](../../WINDOWS_QA.md).
