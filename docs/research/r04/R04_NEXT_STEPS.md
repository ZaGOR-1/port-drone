# R04 · Наступний пріоритет

> Історичний матеріал з `toolchain/performance/r04/R04_NEXT_STEPS.md`. [Реєстр досліджень](../INDEX.md)

Далі профілювати **waypoint і speed setup у `Army._advance`**. У P/D2100 цей шлях оцінили в 2,37 мс/tick при приблизно 1 332 спробах кроку. Розкласти його на читання waypoint, доступ до специфікації типу, lookup країни й множники підсилення, ідеології та голоду. Якщо підтвердиться значна вартість доступу до незмінної таблиці швидкостей, розглянути вузький typed lookup. Порядок множників і live стан країни потребують окремого контролю.

Рідкі reroute та перевірки мостів у цій вибірці дешевші. Для сценарію з частим блокуванням маршруту потрібен окремий checkpoint. Для подальшого рішення про R04 потрібні повтори на тихішому хості та нативний Windows x64 QA. [Аналіз](R04_ANALYSIS.md) · [A/B](R04_AB_RESULTS.md)
