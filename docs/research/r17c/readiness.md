# R17C · Придатність хоста до запуску серії

> Історичний матеріал з `toolchain/performance/r17c.bisE12lZ/readiness.md`. [Реєстр досліджень](../INDEX.md)

60 секунд до старту серії, один інтервал за секунду. Сторонній CPU вимірює незмінний monitor.py R17B. Для початкового preflight застосовуються межа 19% для всіх інтервалів, діапазон до 8 п.п., відсутність двох послідовних відліків memory PSI some понад 2%, CPU нижче 80 °C, GPU нижче 70 °C та відсутність активних паралельних compilation, packaging або benchmark jobs. Перед кожним окремим плечем потрібні ті самі перевірки короткого preflight з шістьма секундними інтервалами. Для вже завершених A/B застосовуються критерії придатності R17B, зокрема медіана стороннього CPU до 19% та різниця між медіанами A і B до 3 п.п.

Запис показників per-core, runnable tasks, clocks, температур, PSI і swap є діагностичним. Порівняння frame-time percentiles враховує медіани, розкид і напрямки окремих придатних пар. Історичні пари не зараховуються до мінімуму чотирьох нових придатних пар.
