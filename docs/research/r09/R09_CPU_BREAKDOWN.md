# R09 · CPU breakdown

> Історичний матеріал з `toolchain/performance/r09.vlpdda5t/R09_CPU_BREAKDOWN.md`. [Реєстр досліджень](../INDEX.md)

Таймери рахують синхронний час на головному потоці. Inclusive охоплює вкладені виклики, exclusive віднімає безпосередньо вкладені виміряні scopes. Exclusive може містити код невиміряних дочірніх функцій. Це wall-time, який також може включати витіснення планувальником. CSV має загальний час, середнє, p50/p95/p99, максимум і calls на тик/кадр для кожної функції. Перцентили викликів — верхні межі гістограм. Крок від 1 мкс для малих викликів до 8192 мкс для довгих. Максимуми точні в межах точності годинника. Нативні heap allocations, пропускна здатність пам’яті та scheduler/present trace — NOT RUN.

## Першопричина витрат ArmyFire._impact

Окремий діагностичний staging рахує фактичні ітерації. Рядки — неперетинні частини одного виклику, з незначним залишком у батьківському scope. Лічильники всередині циклів мають власну ціну. Обидва сценарії зберегли до/після NetHash, movement hash і CRC команд.
