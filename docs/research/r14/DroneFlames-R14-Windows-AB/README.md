# DroneFlames R14 · Windows x64 A/B

> Історичний матеріал з `toolchain/performance/r14.GEz1Tr3B/ab-stage/DroneFlames-R14-Windows-AB/README.md`. [Реєстр досліджень](../../INDEX.md)

- A — beta 8c83d91d06989cc3857c7560c4690188bf88a964.
- B — R14 8a7ddc2c3d4f3659d4d1902e0f1ce17e2dd1b256.
- Обидва варіанти 0.36.5, official Godot 4.7.2. Синтетичний D2100 checkpoint перевірено через Save/Load на тому самому змісті A і B.

Розпакуйте комплект у каталог із правом запису. Запустіть у PowerShell  або . Кожен запуск створює свій профіль у Runs, копіює той самий checkpoint і вимикає updater. У головному меню завантажте слот 1. Для зіставлення зберігайте однакові швидкість, камеру та тривалість вікна вимірювання. Чергуйте A/B та B/A. Графічні аргументи задають 1280×720, Vulkan Mobile і VSync off.

Це ручний Windows A/B на релізних QA-збірках. Він відтворює один стан Save/Load, а автоматизовані Linux-виміри використовували інструментований fixture і визначений потік lockstep-команд. Фізичний Windows запуск комплекту ще не перевірено. Для журналів дивіться Runs, для ідентичності — SHA256SUMS.txt і BUILD_PROVENANCE.json кожного варіанта.
