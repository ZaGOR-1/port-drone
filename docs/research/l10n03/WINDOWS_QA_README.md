# DroneFlames · L10N-03 · Windows 11 QA

> Історичний матеріал з `toolchain/l10n03-qa.vfFa4l/bundle/WINDOWS_QA_README.md`. [Реєстр досліджень](../INDEX.md)

Використай `DroneFlames-PR7-Windows-x64-0e8316e.zip` поруч. Це перевірений пакет для коду `0e8316ee167b11a90925e33a126290b6848d9986`. Версія `0.36.0`, official Godot `4.7.2.stable.official.ed1daf0bf`.

1. Розпакуй ZIP в окрему теку на Windows 11. Залиши всі три DLL поруч з EXE. Запусти перевірку нижче з теки цього README.
2. У розпакованому пакеті відкрий `WINDOWS-QA.txt` і виконай інструкцію зі створення ізольованого профілю. Для перевірки збереження мови запускай наступні сеанси з того самого QA PowerShell через `Start-DroneQA`. Функція створює окремий engine log на кожен запуск.
3. Пройди [checklist](WINDOWS_QA_CHECKLIST.md) і заповни [результати](WINDOWS_QA_RESULTS.md). Звір тип платформи, Windows build і SHA EXE. Для фізичного LAN/Steam використовуй окремі тестові сеанси двох ПК з однаковими SHA EXE та DLL.

```powershell
.\collect-qa.ps1 -PackageDir .\DroneFlames-PR7-Windows-x64-0e8316e |
    Set-Content -Encoding UTF8 .\qa-environment.json
```

Заміни шлях `-PackageDir` на фактичну теку розпакування. У разі перенесення ZIP передай шлях `-ZipPath`. Скрипт звіряє SHA256 ZIP, EXE, DLL і provenance, знімає версію Windows та перелічує наявні імена журналів штатних launcher. Для другого клієнта додай `-Peer guest`. Результат іде у stdout. Скрипт працює локально й зберігає налаштування ОС. Вміст журналів, профілі та дані облікових записів залишаються поза збором.

У QA-пакеті updater вимкнено. Тестуй його помилки окремо на debug fixture з локальними відповідями. Для пошкодженого слота використовуй лише вільний слот у синтетичному QA-профілі. Перед передаванням журналів залиш лише релевантні фрагменти без Steam ID, токенів, назв приватних облікових записів і шляхів користувача.
