# Windows 11 · checklist

> Історичний матеріал з `toolchain/l10n03-qa.vfFa4l/bundle/WINDOWS_QA_CHECKLIST.md`. [Реєстр досліджень](../INDEX.md)

Виконай базовий список у `uk`, `ru`, `en` за матрицею 100%, 125%, 150% Windows DPI. DPI встановлюй через Параметри → Система → Дисплей → Масштаб. Перезапускай гру після зміни Windows DPI. Занотуй роздільність і окремо внутрішній UI scale.

| ID | Дія | Очікуване |
| --- | --- | --- |
| W01 | Запуск і екрани завантаження | Прогрес і підказка активною мовою, без обрізання. |
| W02 | Головне меню й Settings | Довгі назви, заголовки й кнопки поміщаються, нижні пункти досяжні прокруткою. |
| W03 | Зміна мови з відкритих Settings у партії | `ru → uk → en → uk` оновлює меню та HUD після повернення. Після перезапуску з тим самим профілем лишається `uk`. |
| W04 | New Game, Continue, Save/Load | Синтетичний save відкривається після перезапуску. Другий запис і rollback повертають очікувану точку. |
| W05 | Пошкоджений невикористаний слот | Дії з `WINDOWS-QA.txt` лише в ізольованій теці. Локалізована відмова, решта слотів доступні. |
| W06 | HUD, план, штаб, накази й tooltips | Перевір стадії казарм, склад боєприпасів, відхід, режим, автопоповнення й довгі військові підказки. |
| W07 | Економіка й дипломатія | Виробіток, вартість і ресурс. Альянс, відкликання проходу, земельна угода, статус відмови. |
| W08 | Хроніка, події й сповіщення | Заповнена хроніка і лічильник кадрів. Після зміни мови перевір старе зведене повідомлення. |
| W09 | Multiplayer UI | Порожній список, довгі назви, невдале підключення, очікування гравців і столиць. |
| W10 | LAN на двох ПК | Lobby, join, leave, reconnect того самого слота до 60 с і новий наказ. Snapshot/resync підтвердь журналом хоста й гостя. |
| W11 | Steam на двох ПК | Повтори transport-кейси з `-Transport Steam` у тестових сеансах. |
| W12 | Updater з окремим debug fixture | Локальний HTTP, та сама версія, невалідний JSON, втрата зв’язку, HTTP error, size, digest, відмова запису. Звір переклад і SHA початкового EXE. Дію retry запиши, якщо її показав перевірений шлях. |

У найтіснішому вікні додатково перевір W02, W05–W09 при внутрішньому UI scale 70% і 130%. Збережи текст дефекту та скриншот. Власні назви, шляхи, нікнейми й діагностичні коди оцінюй за контекстом.
