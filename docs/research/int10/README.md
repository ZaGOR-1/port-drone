# INT-10 · відтворення R17 fixture

> Історичний матеріал з `toolchain/int10.GjFgeuwy/fixture/README.md`. [Реєстр досліджень](../INDEX.md)

`bash run.sh` створює нові ізольовані профілі та запускає один і той самий тест на official Linux PCK бази 0.36.8 і R18B 0.36.8. Точний checkpoint, обидва PCK та їх SHA256 наведено в `inputs.sha256`. Перевірені звіти збережено в `A/result.json` і `B/result.json`.

Початкова помилка відтворилася на гілці A в R18B до запуску B. `Array` у тернарному присвоєнні не відповідав типу `Army.units: Array[Unit]`. Ізольоване виправлення присвоює порожній типізований масив на першій ітерації та наявний масив на другій. Кількість присвоєнь, виклики production setter, порядок restore та всі 33 перевірки збережено. Production diff R18 змінює в Army лише виключення з save/load. R17 setter, revision accounting та membership code лишаються ідентичними beta.

На official PCK незалежний запуск дав 33/33 на A та B. Обидва звіти побайтно збігаються між собою і з приймальними звітами R18B. Початковий журнал і точний diff fixture збережено.
