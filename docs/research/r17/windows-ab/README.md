# DroneFlames R17 — ручний Windows x64 A/B

> Історичний матеріал з `toolchain/performance/r17-final-profile-b.9tC9OIb6/windows-ab/README.md`. [Реєстр досліджень](../../INDEX.md)

A — official Windows QA baseline `d6a38e8` з INT-08. B — official Windows x64 R17. Обидва мають версію 0.36.7. SHA256 архівів і спільного сейву є в SHA256SUMS. Звір SHA перед запуском.

Розпакуй A та B в окремі каталоги. Для кожного варіанта скопіюй `slot_1.save` у `test-user\Roaming\Godot\app_userdata\DroneFlames\saves\slot_1.save` всередині відповідного каталогу. Це синтетичний активний D2100 дисковий сейв бази 0.36.7 для спільного ручного сценарію. Автоматичний Linux Late E використовував окремий snapshot.

Запускай `Run-DroneFlames.ps1 -Mode Gui` з каталогу відповідної збірки. Сценарій ізолює профіль, вимикає updater та ініціалізацію Steam у грі. Завантаж слот 1 і використовуй однаковий режим рендерингу, роздільність, VSync, позицію камери та зум. Перед новим плечем віднови спільний сейв, щоб стартовий стан збігався. Чергуй A/B, B/A, B/A, A/B. Фіксуй FPS, 1% low, frame p99, помітні фризи, збої і фонові задачі. Звичайні програми можуть працювати. Окрему перевірку фізичних LAN/Steam проводь на двох однакових збірках за штатним LAN/Steam QA.
