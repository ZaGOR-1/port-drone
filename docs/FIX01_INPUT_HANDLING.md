# FIX-01 — ввід миші

GUI отримує wheel першим. Фон меню зупиняє прокидання wheel. Gameplay у відкритому меню не отримує мишу та жести. Wheel або трекпадний жест над іншим Control не рухає карту, якщо GUI пропустив подію далі. Після закриття меню wheel знову масштабує карту.

Desktop press і release використовують наявний шлях map tap/drag, зберігають поріг руху 6, але пропускають touch double-tap zoom і touch double-tap drag. Явний double click по фронту зберігає відкриття меню фронту. Панорамування ЛКМ після порогу, ПКМ і середньою кнопкою зберігається.

Рух карти потребує активного натиснення й відповідної button mask. Якщо GUI поглинає release, відкладене очищення скидає саме попереднє натиснення без map tap, наказу або завершення drag. Втрата фокуса й відкриття паузи скидають залишковий стан. Shift+ЛКМ і Shift+рамка продовжують використовувати чинне виділення армій. Звичайний правий клік без drag проходить чинний шлях наказу.

`PROTO=7`, `SIM_REV=v036-integration-1`, `Save.FORMAT=1`. Механізми симуляції, NetHash, мережеві повідомлення, формат збережень і переклади лишилися без змін.
