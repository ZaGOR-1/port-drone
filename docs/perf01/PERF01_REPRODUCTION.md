# PERF-01. Відтворення

`fixture.gd` додає Main із фактичним HUD, камерою й оверлеями у діагностичний PCK. Вона пропускає фоновий світ головного меню, генерує карту 512×512 із seed `20261016`, засновує столицю і готує контрольовану територію. 250 установок створює штатний `Military.build` без списання ресурсів на підготовці. Кожна сама отримує дві ракети. Симуляція зупинена перед генерацією світу і під час вимірювання UI. Водночас Main, HUD і рендеринг працюють. До підтвердження в сценарії 253 facilities, 8 821 об’єктів світу й 0 наземних юнітів.

Вибір виконується через пари `InputEventMouseButton` у viewport. Крок сітки 24 px перевищує ігровий радіус захоплення 22 px. Порядок кліків розводить сусідні за часом кліки й обходить область HUD. Логічна та фізична роздільності збігаються. Під час набору цілей між серіями по вісім кліків пропускається один кадр, а перші десять кліків виконуються по одному за кадр. Сценарій перевіряє кожну зміну кількості та відхилення 501-го кліку за вичерпаного боєзапасу. Максимум у цьому fixture дорівнює 500 і залежить від готового боєзапасу.

Фіксовані параметри GUI — viewport 1480×950, zoom 1.0, центр карти (1024, 1024), російська мова протягом A/B, однаковий official Linux release 4.7.2 і OpenGL Compatibility. Окремі вікна по 26 кадрів знімаються для спокою й руху курсора при 10, 50, 100, 150, 199, 200, 201, 250, 300 і 500 цілях. Після останньої точки виконано скасування/відновлення чернетки та штатне підтвердження кнопкою StrikeSheet. Симуляція виконує 105 кроків по `SIM_DT`, включно з першими фактичними пусками.

```sh
toolchain=~/projects/droneflames-toolchain
DISPLAY=:87 LIBGL_ALWAYS_SOFTWARE=1 LP_NUM_THREADS=4 \
  bash docs/perf01/run-linux.sh ~/projects/port-drone-perf01 "$toolchain" \
    "$toolchain/performance/perf01/new-B" --verify-ui
```

Запуск використовує окремий Xvfb 1600×1000×24, ізольований профіль, фізичну копію джерел, діагностичний PCK, pinned Linux runtime і бібліотеки L01. Для A заміни шлях джерела на checkout `c91e0e6`. Між прогонами зупиняй інші бенчмарки. `PERF01_HEADLESS=1` придатний для перевірок команд і симуляції.

Сирі результати, `/usr/bin/time`, журнали, хеші та локальний ZIP зберігаються у `~/projects/droneflames-toolchain/performance/perf01/`. Віртуальний Linux-дисплей дає контрольне навантаження для A/B. Фізична Windows 11 QA описана окремо. [Windows QA](PERF01_WINDOWS_QA.md)

У режимі `--verify-mp --limit=200` та аналогічно для 50, 300 і 500 цілей fixture використовує справжній шлях від кнопки до черги локального хоста. Профіль render/frame пропускається.
