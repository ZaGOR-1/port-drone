# PERF-01. A/B

A — `beta c91e0e6`. B — UI-коміт `1ebb914` із тією самою версією `0.36.0` для A/B. Послідовність `A8 → B7 → A9 → B8`. У кожному прогоні однаковий початковий NetHash `c8749401923c35cd`, час матчу 0 і та сама камера. Між прогонами фіксувався стан хоста; інші бенчмарки виконано після GUI A/B. Рендерер llvmpipe, Linux Godot 4.7.2 official.

Медіани двох прогонів без руху курсора. FPS обчислено з середнього часу кадру. UI CPU виміряно у `Main._strike_update`, у мс/кадр. Перцентилі nearest-rank рахувалися по 26 кадрах на прогін. За цього розміру вибірки p99 дорівнює максимальному кадру в прогоні.
