# R28 · Критерій дешевого відсіву

Опорна одиниця — мс на виміряний simulation tick, включно з тіками без scan. Для переходу до PoC потрібна правдоподібна чиста економія щонайменше 0,25 мс/тік і 3% acquire CPU в dense D5000. Це поріг локалізації роботи, а не приймання Profile B. Спочатку оцінити копії за R19 та виміряти clear + append_array з RefCounted у Godot 4.7.2. Ця оцінка зараховує всі обліковані unit visits до потенційних копій, включно з fallback, і не віднімає накладних витрат нового обходу. Окремо перевірити, чи усунення копій можливе зі збереженням snapshot membership і порядку за синхронних мутацій.
